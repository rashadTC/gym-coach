# Gym Coach

A personal 4-day training app (strength, hypertrophy, mobility and endurance), built as an installable web app.

**Features:** onboarding with training-day picker, warm-up sets, plate calculator, effort rating, mid-workout exercise swap, lock-proof timers, keep-screen-awake, plan adapted to your equipment and level, live workout mode with set logging and a rest timer, animated exercise demos with glowing target muscles, front/back muscle maps, progression coaching, a custom workout builder, a 42-exercise library, diet targets with meal plans and water tracking, strength charts, weekly muscle volume, badges, and multiple users on one device.

**Data:** saved in the browser on each device, no login needed. Use Profile → Export to back up or move to a new phone.

**Install on iPhone:** open the site in Safari → Share → Add to Home Screen.
